# carbon-footprint-digital-twin
3rd Semester Environment Project
# Project Title:
# Carbon Footprint Digital Twin for Hostel Energy Systems

## Problem Statement
Campus hostels contribute significantly to electricity-related carbon emissions, yet lack granular monitoring.

## Solution
A software-based digital twin that simulates hostel energy usage using synthetic data and predicts carbon emissions.

## Features
- Digital twin modeling
- Synthetic energy data
- ML-based forecasting
- Carbon emission analysis
- Anomaly detection
- Dashboard visualization

## Tech Stack
Python, XGBoost, Prophet, Streamlit

## Constraints
No real meters, no live sensors, simulation-based approach.

## Future Work
Advanced ML, explainability, carbon optimization.
